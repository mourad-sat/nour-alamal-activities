# موقع أنشطة جمعية نور الأمل

موقع عربي RTL متجاوب لعرض برامج وأنشطة جمعية نور الأمل، مبني بـ HTML وCSS وJavaScript وجاهز للنشر عبر GitHub Pages.

## البنية
- `index.html` الصفحة الرئيسية
- `style.css` التصميم المتجاوب
- `script.js` التفاعل والفلاتر
- `data/activities.json` بيانات الأنشطة
- `404.html` صفحة تحويل بسيطة

## التحديث
يمكن تحديث بطاقات الأنشطة مباشرة من `data/activities.json` دون تعديل JavaScript.

## GitHub Pages
من Settings > Pages اختر Deploy from a branch ثم `main` و`/(root)`.

> ملاحظة: الصور وبيانات التواصل الموجودة حالياً تجريبية ويجب استبدالها ببيانات وصور الجمعية الرسمية.
